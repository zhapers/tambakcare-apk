# TambakCare

**Pantau kualitas air tambak Anda dari mana saja, kapan saja.**

TambakCare adalah sistem monitoring kualitas air tambak berbasis IoT. Sensor di kolam membaca kondisi air secara terus-menerus, lalu datanya langsung tampil di aplikasi Android dan dashboard web Anda.

## Kenapa TambakCare?

- **Data real-time.** Suhu, pH, dan salinitas/TDS (ppt) terbaca langsung dari kolam.
- **Peringatan dini.** Notifikasi langsung ke HP Anda saat kondisi air melewati batas aman.
- **Riwayat rapi.** Semua data tersimpan dan bisa diunduh sebagai CSV, Excel, atau TXT untuk laporan.
- **Jadwal perawatan.** Catat dan tandai perawatan kolam beserta foto buktinya.
- **Banyak perangkat, satu akun.** Kelola beberapa kolam sekaligus dari satu dashboard.

## Unduh aplikasi

Unduh APK terbaru di halaman **[Releases](../../releases/latest)**, lalu pasang di HP Android Anda.

Saat memasang pertama kali, Android akan meminta izin "Instal aplikasi tidak dikenal". Izinkan untuk browser atau pengelola file yang Anda pakai.

Aplikasi hanya bisa dipakai dengan akun TambakCare. Akun dibuatkan oleh tim kami setelah pembelian.

## Dashboard web

Buka **[tambak-care.vercel.app](https://tambak-care.vercel.app)** untuk memantau tambak lewat browser, tanpa perlu memasang aplikasi.
