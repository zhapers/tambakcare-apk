# Changelog

Semua perubahan aplikasi Android TambakCare. Unduh APK terbaru di halaman [Releases](https://github.com/zhapers/tambakcare-apk/releases/latest).

## v0.2.11 (2026-11-09)

- Aplikasi sekarang terhubung ke alamat web baru `www.tambakcare.my.id`, termasuk link situs web di Tentang aplikasi.

Update dari dalam aplikasi atau pasang langsung di atas versi lama, tidak perlu uninstall.

## v0.2.10 (2026-11-09)

- Akun Admin kini punya tab Admin sendiri di menu bawah, berisi Batas aman sensor, Telegram & backup, Kelola jadwal perawatan, dan Kelola pengguna. Menu bawah bisa digeser ke samping.
- Aplikasi tidak lagi langsung menawarkan update saat dibuka. Kalau ada versi baru, muncul pemberitahuan kecil berisi ringkasan isi update.
- Tentang aplikasi punya tombol Cek update. Tombol Update sekarang hanya muncul kalau ada versi baru.
- Setelah update, catatan perubahan lengkap tampil sekali saat aplikasi pertama kali dibuka.

Update dari dalam aplikasi atau pasang langsung di atas versi lama, tidak perlu uninstall.

## v0.2.9 (2026-11-08)

- Menu bawah Superadmin tidak sumpek lagi: kalau tab tidak muat, menu bisa digeser ke samping. Tab yang aktif otomatis terlihat, dan ada bayangan tipis di tepi sebagai tanda masih ada menu lain.
- File installer update otomatis dihapus saat aplikasi versi baru dibuka, jadi tidak memakan memori HP.

Update dari dalam aplikasi atau pasang langsung di atas versi lama, tidak perlu uninstall.

## v0.2.8 (2026-11-08)

- Mode Superadmin: tab baru Superadmin berisi pilihan pemilik tambak, pemantauan semua Admin (alat online, status, peringatan 24 jam, perawatan, masa sewa) dengan tombol Buka dashboard, dan semua menu admin.
- Tanda Superadmin di header dan keterangan "Masuk sebagai Superadmin" di Beranda.
- Kontrol alat kini selalu 2 tombol. Yang bisa diubah hanya namanya, maksimal 14 karakter supaya tidak terpotong.
- Menu bawah kini melayang, konten terlihat bergulir di belakangnya.

Update dari dalam aplikasi atau pasang langsung di atas versi lama, tidak perlu uninstall.

## v0.2.7 (2026-11-08)

- Menu Akun alat sekarang khusus Superadmin, sama seperti web. Admin cukup menukar kode voucher, lalu alatnya muncul sendiri.

Update dari dalam aplikasi atau pasang langsung di atas versi lama, tidak perlu uninstall.

## v0.2.6 (2026-11-08)

- Menu Admin baru: Kelola pengguna (buat, aktifkan/nonaktifkan, hapus; Superadmin juga bisa ubah peran, ganti password, prioritas, dan pindah pemilik).
- Akun alat: buat dan hapus login alat. Ganti password akun alat khusus Superadmin.
- Voucher (Superadmin): buat kode sewa baru atau perpanjang, salin kode, dan batalkan voucher.
- Kelola alat: tombol Lepas perangkat untuk alat yang sewanya sudah terkunci.

Update dari dalam aplikasi atau pasang langsung di atas versi lama, tidak perlu uninstall.

## v0.2.3 (2026-11-08)

- Menu Admin baru di tab Akun, hanya untuk admin dan superadmin:
  - Batas aman sensor (Suhu, pH, Salinitas) beserta riwayat perubahannya.
  - Pengaturan Telegram dan kirim backup data sekarang ke Discord, Telegram, atau Email.
  - Kelola jadwal perawatan: tambah, ubah, hapus.
  - Kelola alat (superadmin): aktifkan atau nonaktifkan alat.
- Jadwal perawatan bisa ditujukan ke pekerja tertentu (diatur dari web). Pekerja hanya melihat jadwal umum dan jadwal untuk dirinya, ditandai "Untuk: kamu".

Update dari dalam aplikasi (v0.2.2) atau pasang langsung di atas versi lama, tidak perlu uninstall.

## v0.2.0 (2026-11-08)

Tampilan baru di seluruh aplikasi.

- Desain baru: header lebih ringkas, kartu lebih rapi, warna dan ikon seragam.
- Geser layar ke kiri atau kanan untuk pindah tab. Navbar ikut bergerak mengikuti jari.
- Perpindahan tab, buka tutup layar, dan lembar bawah lebih halus.
- Panel Suhu, pH, dan Salinitas baru: angka besar, bar batas aman, dan status Normal, Waspada, atau Kritis.

- Filter Riwayat dan Kotak masuk lebih ringkas.
- Halaman masuk baru dan splash screen yang tidak terpotong.
- Bagian Tentang aplikasi di tab Akun: pengembang, versi, dan tautan situs TambakCare.
- Alat berstatus Prioritas mendapat masa tenggang 7 hari setelah langganan habis.
- Perbaikan stabilitas dan keamanan.
